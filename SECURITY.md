# Security Policy

## Supported version

The `main` branch is the supported production version.

## Reporting a vulnerability

Do not publish suspected vulnerabilities as public GitHub issues.

If you discover a security problem affecting TekVex, report it privately through GitHub's security reporting features when available, or use the private contact channel published on the TekVex website.

Please include:
- the affected page or file;
- clear reproduction steps;
- the security impact;
- any relevant request, URL, or payload.

Do not include payment-card data, credentials, access tokens, or other secrets in a report.

## Scope

The main security scope is the TekVex website and its client-side code. Third-party checkout, hosting, analytics, and delivery providers have their own security boundaries and reporting processes.
